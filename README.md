🌐 Website Project

A responsive website project built using HTML, CSS, and JavaScript, following a web development tutorial as a learning reference.

The project focuses on practicing modern website structure, responsive layouts, styling, navigation, and interactive elements.

📌 Project Overview

This project was created as part of my practice in front-end web development.

It includes sections such as:

🏠 Home
👤 About Us
🍔 Menu / Products
⭐ Testimonials
📞 Contact
📱 Responsive navigation
🔗 Social media links

The design and implementation were developed while following the tutorial provided below, with adjustments and customization made during the development process.

🛠️ Technologies Used
HTML5 — Website structure and semantic markup
CSS3 — Styling, layouts, responsiveness, animations, and visual design
JavaScript — Interactive website functionality
Font Awesome — Icons used throughout the website
✨ Features
Responsive design for desktop, tablet, and mobile devices
Navigation menu
Responsive mobile menu
About section
Product/menu section
Customer testimonials
Contact section
Social media icons
Hover effects and transitions
Responsive image handling
Modern CSS layout using Flexbox
